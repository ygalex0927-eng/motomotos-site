Dynamic Island apps for Mac, compared

Several apps turn the MacBook notch into a Dynamic Island. They fall into two groups: general notch apps built around music, files and the calendar, and apps built for AI coding agents such as Claude Code and Codex. Here is how they differ, and which one fits you.

Updated November 19, 2026

Short answer

  • Free and open source: Boring Notch or Atoll; for coding agents, CodeIsland or Open Island.
  • Music controls and a file shelf, very polished: NotchNook.
  • A notch just for your coding agents — sessions, approvals, usage limits: CodeIsland or Open Island (free), or Vibe Island (paid).
  • One app for your AI agents and everyday widgets (music, calendar, pomodoro, battery, launcher), paid once: motomotos.

General notch apps

NotchNook

From lo.cafe, and one of the best-known notch apps: media controls, a file shelf you drag files through, and the calendar. It’s paid — a lifetime license or a monthly plan, with one license covering two Macs, according to lo.cafe. Pick it if music and quick file drops are what you want from the notch.

Boring Notch

Free and open source (TheBoredTeam/boring.notch on GitHub), community-built, with Dynamic Island-style animations and music controls; it also installs with Homebrew. Pick it if free and open source matters most.

Atoll

Free and open source (Ebullioscopic/Atoll on GitHub): media controls, live activities, lock screen widgets, system stats, a file shelf, clipboard history, calendar previews and timers. A strong pick if you want the most features for free.

Alcove

A paid app (tryalcove.com) that brings Dynamic Island behaviour to the notch, with media controls, alerts and HUDs. Also on Homebrew.

Notch apps for AI coding agents

Vibe Island

A paid app (vibeisland.app) focused on Claude Code and Codex: live 5-hour and weekly usage, session monitoring and approving tool calls from the notch. Pick it if your notch is only for coding agents.

Open-source agent projects

Several free, open-source projects bring coding agents to the notch:

  • CodeIsland (MIT) covers 30+ coding tools: live status, approving tool calls and answering questions from the notch, Claude usage and plan limits, and an iPhone and Apple Watch companion.
  • Open Island (GPL v3) covers 15 agents and many terminals and IDEs: session status, approvals, Claude Code and Codex usage, and one click back to the right terminal. No account, no telemetry.
  • Vibe Notch (formerly Claude Island; Apache 2.0) is built around Claude Code: live sessions, approvals from the notch and chat history.
  • Notchi (GPL v3) is a notch companion for Claude Code and Codex: each session gets a mascot that reacts to what it’s doing, plus usage, cost and token stats.

They focus on coding agents rather than everyday widgets. Pick one of them if you want free and open source and don’t need music, a calendar or a timer in the same place.

  1. Do you code with AI agents? If not, a general notch app is all you need.
  2. Which agents? motomotos follows Claude Code, Codex, Grok, DeepSeek Harness, Hermes and WorkBuddy, and any other tool through motomotos notify. Check each app’s site for its own list.
  3. Once or monthly? motomotos is a one-time $4.99. Some others offer a subscription.
  4. Open source? Boring Notch, Atoll and the open-source agent projects.
  5. Your macOS version. motomotos needs macOS 15 or later.
  6. No notch? motomotos still works: the island sits at the top middle of the menu bar.
