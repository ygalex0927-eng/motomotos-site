How to see Claude Code usage limits in your MacBook notch

Claude Code’s subscription limits come in two windows: 5 hours and 7 days. motomotos puts both percentages and their reset times in your Mac’s notch, so you can check how much is left without leaving what you’re doing.

Updated November 19, 2026

What you need

  • A Mac on macOS 15 or later.
  • motomotos — free for 10 days.
  • Claude Code installed and signed in with a Claude subscription. The 5-hour and 7-day windows are subscription limits.

Steps

  1. Install motomotos. Open Motomotos.dmg, drag Motomotos into Applications and open it.
  2. Open settings. Click the motomotos icon in the menu bar and choose Settings…
  3. Check Claude Code. Go to AI Tools and check Claude Code. You can check several tools; the island shows every one you check, and the closed island shows the first one’s percentage.
  4. Connect Claude Code. Under Checked quotas, click Connect Claude Code. motomotos adds a statusLine entry to ~/.claude/settings.json, backing the file up first. If you already use another status line, motomotos leaves it alone and doesn’t connect.
  5. Use Claude Code once. Run claude in a terminal — the quota card’s Open in Terminal button does it for you. Claude Code only hands its limits to the status line during a session, so the numbers appear after that.
  6. Look at the notch. Rest the pointer on the notch for a glance, or click to open it. The AI quota card shows the 5-hour and 7-day percentages and when each window resets.

How it works

Claude Code passes its rate_limits — how much of the 5-hour and 7-day windows you have used — only to the status line command. motomotos’s status line command shows the model and both percentages in Claude Code’s status line, and copies those two numbers to a file on your Mac. motomotos reads only that file. It doesn’t read, store or forward any keys or tokens.

Undo it

Settings › AI Tools › Disconnect removes motomotos’s status line from ~/.claude/settings.json and nothing else.

If something looks wrong

  • “Connect Claude Code” is greyed out. Claude Code isn’t installed, or another status line is already set in ~/.claude/settings.json.
  • No numbers yet. Use claude in a terminal once after connecting.
  • “Read, but the data is a bit old.” The last numbers are from a while ago. They refresh the next time you use Claude Code.

Codex and Grok, too

Check Codex or Grok CLI in AI Tools as well. Their usage comes from the tools’ own data, with no extra setup. Whatever can’t be read shows as unavailable — motomotos never makes up a number.
